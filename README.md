# Elite Tech Movies

A React movie discovery and watchlist application — with a neon‑dark Elite Tech vibe.  
This project showcases:
- **Movie Search** → powered by OMDb / optional OMDb replacement (like OMDb or DummyJSON for movies)
- **Movie Details** → title, year, poster, and extended info
- **Watchlist System** → save movies locally with persistence
- **Responsive UI** → styled with cyberpunk‑inspired CSS
